# 10 · Settings

[⬅ Back to the User Guide](../user-guide.md)

Tap **SETTINGS** on the main menu. Screen **⚙️ QUANTEX SETTINGS**:

| Button | What it does | Who can use it |
|---|---|---|
| **CHANGE TIMEZONE** | Set the timezone of each feature separately | Everyone |
| **EDIT LIVE SESSION TEMPLATE** | Words printed on your Live Session signals, results, charts and partials | View: everyone · **Change: PLUS / INFINITY** |
| **EDIT LIVE SIGNAL TEMPLATE** | The same for Live Signal cards | View: everyone · **Change: PLUS / INFINITY** |
| **EDIT CHECKER & FUTURE TITLES** | Headings of checker results and future-signal lists | View: everyone · **Change: PLUS / INFINITY** |
| **SUPPORTED BROKERS** | Shows the supported brokers (QUOTEX, TRADOWIX, BINOLLA) | Everyone |
| **PRIMARY BROKER › (name)** | Choose your default broker | Everyone |
| **Back** | Main menu | |

## 10.1 CHANGE TIMEZONE

**🕐 TIMEZONE SETTINGS** lists 11 clocks, each with its active value. Tap one, then pick your UTC offset on **🌐 Select Your Timezone** (e.g. `UTC+6`, `UTC-3`, `UTC+5:30`).

| Button | Used by |
|---|---|
| **Checker TZ** | Live / OTC / Blackout / Whiteout checkers |
| **AI Filter TZ** | AI Filter |
| **Market Filter TZ** | Market Filters |
| **OTC Future TZ** | OTC MARKET FS |
| **Future Live TZ** | Future Live |
| **Live Market FS TZ** | LIVE MARKET FS |
| **Blackout Future TZ** | BLACKOUT FS |
| **Whiteout Future TZ** | WHITEOUT FS |
| **Live Session TZ** | Live Session and Schedule times |
| **Live Signal TZ** | Live Signal entry times |
| **AXTIRON FS TZ** | AXTIRON FS |

> Tip: set every clock to the timezone your broker platform shows, so entry times match exactly.

## 10.2 Editing templates (PLUS / INFINITY)

Open one of the three template screens. Every field shows its **current text**. Changed fields are marked.

| Button | What it does |
|---|---|
| **Change (field name)** | Opens the editor: shows the current text and the maximum length. Send the new text (it is styled automatically). **Cancel** to go back |
| **RESET ALL CHANGED** | Asks *"⚠️ Reset … Template?"*. **YES, RESET** restores all defaults, **NO, CANCEL** keeps them |
| **Back** | Back to Settings |

After saving: **Edit More** or **Back to Settings**.

On FREE and STARTER you can open these screens and see everything, but changing shows *"🔒 You're not authorized to change this. Template editing is a premium feature…"*

### Live Session template fields

| Field | Max length | Default |
|---|---|---|
| Signal Title | 26 | QUANTEX-BOT SIGNAL |
| Result Title | 26 | Q-BOT RESULT |
| Chart Title | 24 | QUANTEX - BOT ULTRA |
| Chart Watermark | 12 | QUANTEX |
| Username | 32 | (your session username) |
| Partial Title | 26 | QUANTEX-BOT PARTIAL |
| Partial Footer | 34 | QUANTEX-BOT |

### Live Signal template fields

Same seven fields. Defaults: QUANTEX-BOT SIGNAL · QUANTEX-BOT RESULT · QUANTEX BOT · QUANTEX · @X_Akash_Owner · QUANTEX-BOT PARTIAL · QUANTEX-BOT.

### Checker & Future titles

| Field | Max length | Default |
|---|---|---|
| Checker Title | 26 | QUANTEX BOT CHECKER |
| Future Signal Title | 26 | QUANTEX BOT FUTURE |

## 10.3 PRIMARY BROKER

**🏦 PRIMARY BROKER** shows the selected broker and whether it is used everywhere.

| Button | What it does |
|---|---|
| **QUOTEX / TRADOWIX / BINOLLA** (✓ = current) | Makes it your primary broker (*"… is now your primary broker."*) |
| **USE THIS BROKER IN ALL FEATURES — ON/OFF** | **ON**: no feature asks you to choose a broker any more. **OFF**: every feature asks |
| **Back** | Back to Settings |
